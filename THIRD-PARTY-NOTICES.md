## Maintaining this file

`licenses/qt-components.md` is generated by `scripts/third-party-notices.py` from the SBOMs that Qt
installs. Run it again after upgrading Qt or changing the deployed Qt modules, and add the text of
any new SPDX license identifier it lists to `licenses/` (from
<https://github.com/spdx/license-list-data/tree/main/text>).
